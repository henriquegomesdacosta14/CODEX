# AGENTS.md

Este repositório tem três sistemas independentes:

- **Raiz (`index.html`, `admin.html`, `api.php`, `data/`)**: site devocional do casal, publicado na Hostinger. Não mexa nele sem pedido explícito.
- **`secretaria-whatsapp/`**: secretária virtual de WhatsApp de uma clínica, com IA. Ao trabalhar nessa pasta, siga `secretaria-whatsapp/AGENTS.md`.
- **`canal-dark/`**: pipeline em Python que produz vídeos para um canal dark no YouTube (histórias bíblicas), com aprovação humana antes de publicar. Ao trabalhar nessa pasta, siga `canal-dark/AGENTS.md`.

A Hostinger publica a branch `main`. Trabalhe em uma branch separada e nunca commite chaves, senhas ou dados reais.
